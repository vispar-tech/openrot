# Участие в разработке openrot

> [English](CONTRIBUTING.md) · **Русский**

Спасибо за участие! Проект небольшой и дружелюбный. Приветствуются вопросы,
issue и pull request. Ниже — как всё устроено, чтобы ваш вклад лёг чисто.

## Структура проекта

- `openrot/` — сам пакет (`openrot/cli.py` — точка входа Typer).
- `tests/` — набор `pytest`, покрывающий пакет.
- `Makefile` — канонические команды разработки (`make check`, `make fix`, ...).
- `pyproject.toml` — зависимости и настройки инструментов (ruff, mypy, pytest).

## Установка

Требуется Python 3.14+ и [Poetry](https://python-poetry.org).

```bash
poetry install            # ставит зависимости + dev-группу
pre-commit install        # опционально: ruff/mypy при каждом коммите
```

## Цикл разработки

```bash
make lint     # ruff check + ruff format --check (без изменения файлов)
make types    # mypy strict по openrot/
make test     # pytest
make check    # lint + типы + тесты, всё сразу
```

Автоформатирование и автоправки перед коммитом:

```bash
make fix      # ruff format + ruff check --fix (меняет файлы)
```

## Перед открытием pull request

1. Убедитесь, что `make check` проходит локально. CI запускает те же
   [проверки](.github/workflows/ci.yml) (ruff, mypy, pytest) на каждом push.
2. Выполните `make fix`, чтобы форматирование было единообразным.
3. Держите изменения сфокусированными и добавляйте тесты на новое поведение.
   Для исправлений багов — регрессионный тест; для новых команд/флагов — тоже
   покрытие.
4. Пишите понятное сообщение коммита: что и зачем меняется.

## Стиль кода

- Python 3.14+, [ruff](https://docs.astral.sh/ruff/) с конфигом репозитория
  (`line-length = 88`, двойные кавычки) и строгий [mypy](https://mypy-lang.org).
- Следуйте окружающему стилю: читаемые небольшие функции, docstring у публичных
  символов (правила D-группы проверяет ruff).
- Без комментариев в коде, если только они не проясняют что-то неочевидное.

## Тесты

Набор лежит в `tests/` и использует обычный `pytest`. Запуск одного файла или
теста:

```bash
poetry run pytest tests/test_foo.py
```

## Сообщение об ошибке

Заведите issue через [шаблон баг-репорта](.github/ISSUE_TEMPLATE/bug_report.md)
и приложите:

- ваши команды и их вывод (например, `openrot doctor`),
- ваш `config.yaml` (уберьте чувствительное),
- ОС и то, где вы работаете: хост или Docker,
- версии sing-box и, если актуально, warp-cli.
